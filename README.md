# VANTAGE

**Configure your device the way you want.**

VANTAGE is a Windows optimization and customization utility. Its primary focus is Windows tweaks, while also providing a wide range of useful features for everyday use — from live system monitoring to CPU core affinity configuration.

## Features — VANTAGE 1.0.0 Beta

### 1. System Analysis

Comprehensive system analysis, problem detection, hardware health assessment, and recommendations to improve overall performance.

![System Analysis](./Assets/ANALYS.png)

### 2. My Games

A list of installed games with individual settings, profiles, and recommendations tailored to each game.

![My Games](./Assets/GAMES.png)

### 3. Tweaks

Windows customization with detailed descriptions of each tweak, its potential impact, and the ability to apply or revert changes.

![Tweaks](./Assets/TWEAKS.png)

### 4. Game Mode

Prepare Windows for gaming by applying gaming-related tweaks and configuring the system to reduce background activity.

![Game Mode](./Assets/GAMEMODE.png)

### 5. App Optimization

Optimize applications such as Edge, Chrome, Discord, Spotify, and others to reduce resource usage and improve performance.

![App Optimization](./Assets/APP.png)

### 6. Power Management

Manage Windows power plans — apply, create, remove, and configure power schemes.

![Power Management](./Assets/POWER.png)

### 7. Display

Configure screen resolution, refresh rate, scaling, and other display-related settings.

![Display](./Assets/DISPLAY.png)

### 8. Network

Manage network settings, optimize DNS, configure network parameters, and apply network tweaks to improve connection stability.

![Network](./Assets/NETWORK.png)

### 9. Processes

Manage running processes and configure CPU core priorities for individual applications to optimize their performance.

![Processes](./Assets/PROCESSES.png)

### 10. Interrupts

Configure MSI mode, interrupt priorities, and device-to-CPU core affinity to improve system responsiveness.

![Interrupts](./Assets/INTERRUPTS.png)

### 11. GPU Reservation

Manage GPU resource reservation and system settings related to graphics processing.

![GPU Reservation](./Assets/GPU.png)

### 12. Live Monitoring

Record and monitor system resource usage in real time while gaming, including performance metrics and system activity.

![Live Monitoring](./Assets/MONITORING.png)

### 13. Benchmark

Test your PC's performance, evaluate benchmark results, and keep a history of previous tests for comparison.

![Benchmark](./Assets/BENCHMARK.png)

### 14. Drive Health

Monitor storage health, temperature, wear levels, detect errors, and evaluate drive reliability.

![Drive Health](./Assets/DISKS.png)

### 15. Connection Test

Check connection latency (ping), packet routes, and server accessibility.

![Connection Test](./Assets/PING.png)

### 16. Anti-Cheat Ready

Check system compatibility with anti-cheat requirements, including Secure Boot, TPM, and other security-related requirements.

![Anti-Cheat Ready](./Assets/ANTICHEAT.png)

### 17. Cleanup

Remove temporary files, cached data, and system junk to free up storage space.

![Cleanup](./Assets/CLEANUP.png)

### 18. Fixes

A collection of fixes for common Windows, game, driver, and system-related issues.

![Fixes](./Assets/FIXES.png)

### 19. Installed Applications

View installed applications, uninstall programs, and search for leftover files.

![Installed Applications](./Assets/INSTALLED.png)

### 20. App Installer

Browse available applications, select what you want to install, and manage the installation queue.

![App Installer](./Assets/INSTALLER.png)

### 21. Built-in Applications

Manage built-in Windows applications, including the removal of unwanted apps and components.

![Built-in Applications](./Assets/BUILTIN.png)

### 22. Startup

Manage applications and services that launch with Windows to control background activity and startup time.

![Startup](./Assets/STARTUP.png)

### 23. Tools

A collection of system utilities for backups, memory management, CPU core checks, and system diagnostics.

![Tools](./Assets/TOOLS.png)
